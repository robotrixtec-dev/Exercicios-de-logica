# Exercicios OM

Esta pasta reúne os 7 exercícios do projeto em linguagem Visualg (Portugol). Os algoritmos foram adaptados para uma estrutura mais clara, com comentários iniciais e lógica funcional para uso no Visualg.

## Lista de exercícios

1. Verifica se um número é positivo, negativo ou zero e informa se é par ou ímpar.
2. Compara dois números, mostra o maior e calcula a diferença entre eles.
3. Soma dois valores e informa se o total é menor, maior ou igual a 10.
4. Calcula a média de três notas e define a situação do aluno.
5. Converte Celsius para Fahrenheit e Kelvin e classifica a temperatura.
6. Calcula o valor de compra com desconto conforme preço e quantidade.
7. Mostra a tabuada de um número de 1 a 10.

## Como abrir no Visualg

- Abra o Visualg;
- Clique em Arquivo > Abrir;
- Selecione o arquivo .alg desejado;
- Execute com F9 ou na opção Executar.

## Observação

Os códigos estão em português e seguem a sintaxe do Portugol/Visualg, mantendo o mesmo raciocínio dos exercícios originais em Visual Basic.
